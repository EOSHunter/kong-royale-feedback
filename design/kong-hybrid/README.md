# Kong Royale · Hybrid design system

Toon with fewer containers: the Toon colours, fonts, outlines and chunky controls, with Premium's open rows and typography for content. Logos are in `../kong-toon/logos/`.

| File | Use |
|---|---|
| `design-system.md` | Source of truth |
| `tokens.css` | Same tokens as Toon |
| `implementation-prompts.md` | Staged prompts for implementing it in the game |
| `reference/toon-and-hybrid.css` | Prototype CSS (Hybrid rules are scoped to `html[data-ds="toon"][data-variant="hybrid"]`) |
| `screens/*.jpg` | The 14 screens captured from the Hybrid prototype |
